## ## 📹 6. SD to HD Video Upscaler

<p align="center">
  <img src="https://raw.githubusercontent.com/Brajesh31/asset/main/video-upscaler-banner.png" alt="Video Upscaler Banner" width="700">
</p>

A Python tool to upscale Standard Definition (SD) videos to High Definition (HD) using traditional interpolation techniques. The script efficiently resizes video frames while preserving and synchronizing the original audio.

* **Repository Link:** [**github.com/Brajesh31/Video-quality-conversion-SD-to-HD-**](https://github.com/Brajesh31/Video-quality-conversion-SD-to-HD-)

### ### ✨ Key Features:
* Upscales video resolution from 640x480 to 1280x720.
* Uses Cubic Interpolation for higher-quality resizing.
* Preserves the original audio track using FFmpeg.
